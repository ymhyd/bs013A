源码+数据库+全套环境和工具资源+本地部署教程

前端技术： Html、Css、Js、Vue3.4、Element-Plus

数据库管理工具：Navicat10以上版本

环境配置软件： JDK17 + Maven3.6.3

前端Nodejs：16+

浏览器：谷歌浏览器

### 五、项目介绍
项目编号：bs013A

停车场管理系统面向管理员、用户，提供项目核心业务等功能，实现各角色在系统中的实际业务协作。

角色：管理员、用户

管理员功能：工作台停车运营数据总览、车主账号管理、车位资源管理、停车收费规则配置、临停预约核验、车辆出入场登记管理、停车订单结算与异常停车处理、停车公告与首页轮播图管理。

用户功能：车主注册与登录、首页查看分区余位与停车公告轮播图、选择分区车位与车辆时段提交临停预约、查看停车记录与预约入场缴费进度、取消未入场的车位预约、停车订单模拟缴费、接收停车消息通知、个人中心维护资料管理车辆与修改密码。
